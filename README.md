# KAYOS: Nullborn — Bellmoor slice (web demo)

Compiled Godot 4.7 web build of the Bellmoor vertical slice.
**Build output only — no game source.**

Touch controls: left thumb walks, right thumb looks, buttons bottom-right
(E interact · CR crouch · HD hood · RUN sprint · J journal).

Renderer is `gl_compatibility` — Godot forces this on web — so there is no SDFGI
and no volumetric fog here. The desktop build is Forward+ and looks different.

Delete this repository at any time to take the demo offline.
